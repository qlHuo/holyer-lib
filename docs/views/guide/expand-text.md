# expand-text 可展开文本

## 组件概述  
`HiExpandText` 是一个支持**行数限制与动态展开/收起**的文本容器组件。当文本内容超过指定行数时，自动显示“展开”按钮；点击后全文展示，并可切换回收起状态。适用于长文本摘要、评论预览、说明文案等场景。

## 基础使用  
通过 `lineClamp` 控制收起状态下的最大行数，组件自动检测是否溢出并决定是否显示切换按钮。支持自定义“展开/收起”文案或通过插槽完全自定义触发器。

:::demo
```vue
<template>
<ClientOnly>
  <HiExpandText
    :content="longText"
    :line-clamp="2"
    :label="['查看更多', '收起']"
  />
</ClientOnly>
</template>

<script>
export default {
  data() {
    return {
      longText: '这是一段较长的示例文本，用于演示 HiExpandText 组件在超过指定行数时自动显示“展开”按钮的功能。用户点击后可查看完整内容，并支持再次点击收起，支持响应式。这是一段较长的示例文本，用于演示 HiExpandText 组件在超过指定行数时自动显示“展开”按钮的功能。用户点击后可查看完整内容，并支持再次点击收起，支持响应式。'
    };
  }
};
</script>
```
:::

## Props 属性  

### HiExpandText 属性  

| 属性名     | 类型            | 默认值               | 说明 |
|------------|-----------------|----------------------|------|
| content    | String          | `''`                 | 要显示的文本内容（也可通过默认插槽传入） |
| label      | Array | `['展开', '收起']`   | 切换按钮文本：`[0]` 为展开时显示的文本，`[1]` 为收起时显示的文本 |
| lineClamp  | Number          | `2`                  | 收起状态下允许显示的最大行数 |

> 💡 **内容优先级**：若同时提供 `content` 属性和默认插槽，**默认插槽内容优先渲染**。  
> 💡 **响应式检测**：组件会监听窗口尺寸变化及自身容器 resize，自动重新判断是否需要显示切换按钮。

## Slots 插槽  

| 插槽名      | 说明 |
|-------------|------|
| default     | 自定义主文本内容（替代 `content` 属性） |
| toggleText  | 自定义“展开/收起”按钮文本（替代 `label` 配置） |

> ✅ 示例：  
> ```vue
> <template #toggleText>
>   <span style="color: #1890ff; font-size: 12px">
>     {{ isExpanded ? '收起 ▴' : '展开 ▾' }}
>   </span>
> </template>
> ```

## Events 事件  

| 事件名  | 说明                     | 回调参数 |
|---------|--------------------------|----------|
| toggle  | 点击“展开/收起”按钮时触发 | `Boolean`：当前是否处于展开状态 |

> 🔄 可用于埋点统计、联动其他 UI 元素等。

## Methods 方法  

| 方法名  | 说明                         | 参数 | 使用场景 |
|---------|------------------------------|------|----------|
| update  | 手动触发溢出检测逻辑         | 无   | 当外部动态修改内容后，需主动调用以更新 toggle 显示状态 |

> ✅ 示例：  
> ```js
> this.$refs.expandText.update();
> ```

---

✅ **适用场景**：用户评论、商品描述、帮助文档、日志摘要等需要“默认折叠 + 按需展开”的文本展示区域。  
✅ **兼容性**：基于 `-webkit-line-clamp` 实现，兼容所有现代浏览器（Chrome/Firefox/Safari/Edge）。
